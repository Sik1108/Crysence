# 泣语 CrySense MVP

一个面向新手父母的婴儿哭声分析与照护辅助 Web 原型。

## 运行

直接双击 `index.html` 可以浏览界面和演示分析。由于浏览器的安全限制，真实麦克风录音通常需要通过 `localhost` 打开：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现

- 移动端首页与今日概况
- 麦克风授权、10 秒录音、实时波形和基础音量检测
- 明确标记的模拟三分类推理与置信度分流
- 高置信度照护建议和低置信度检查清单
- 分析反馈、本地历史记录与近 7 天趋势
- 医疗安全提示与响应式界面

## 重要说明

当前版本的分析结果由演示算法生成，不具备真实识别能力，也不构成医疗建议。正式产品必须接入经过可靠数据训练、校准和验证的模型，并完成隐私、安全与专业审核。

产品要求、验收标准、数据和 AI 方案详见 `PRD.md`。
